# AI Resume Analyzer & ATS Optimizer

An AI-powered web application that analyzes resumes, checks ATS compatibility, and helps users improve their resumes for better job opportunities.

---

## 🚀 Features

- Resume ATS Score Analysis
- Keyword Optimization
- Resume Parsing
- PDF Resume Upload
- AI Suggestions for Improvement
- User-Friendly Interface
- Fast and Accurate Analysis
